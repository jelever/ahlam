# أحلام القمر — AHLAM ALQAMAR

Digital product catalogue for **شركة أحلام القمر للتجارة** (Ahlam Alqamar
Trading Company), aimed at wholesale customers and trade partners. It is a
showcase, not a shop: no prices, cart or payment, by the client's brief.

- Arabic (default, right-to-left) at `/`, English at `/en/`
- Static HTML generated by `build.py` (Python, Jinja2, Pillow)
- Hosted on GitHub Pages: https://jelever.github.io/ahlam/

## Run it

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt      # Windows (bin/ elsewhere)
.venv/Scripts/python build.py --serve 8741
```

Open http://localhost:8741/ahlam/. The first build converts every photo and
takes about half a minute; later builds reuse `.cache/`.

`python build.py` builds into `_site/` and runs the checks: every internal
link resolves, every image has alt text and dimensions, each page exists in
both languages, and no page uses shop wording (price, cart, buy…). A
failing check exits non-zero, and CI will not deploy.

## Change the content

Everything the client may change is in `content/`:

| File | What it holds |
|---|---|
| `site.yml` | name, contact details, public address |
| `catalog.yml` | collections, products, their fields and photos; home page hero and featured rows |
| `strings.yml` | every piece of interface text, in Arabic and English |
| `images/<collection>/<product>/` | original photos (ASCII file names) |

**Add a product:** put its photos in `content/images/<collection>/<slug>/`
and add an entry under `products:` in `catalog.yml`. The first image is the
one shown everywhere; the others (other colours, real-life photos) appear only
on the product's own page. List only the fields the client supplied.

**Launch a "coming soon" collection:** give it a `summary` and a `cover`,
add its products, and remove `soon: true`.

**Contact details:** replace the `[placeholders]` in `site.yml`. Once the
WhatsApp number is set, every "contact us to enquire" button opens WhatsApp
with the product's name filled in. `python build.py --release` fails while
any placeholder remains.

**Custom domain:** set `base_url` to the domain, set `base_path` to `""`, add
the domain under Settings → Pages, and point DNS at GitHub Pages.

## Deploy

Pushing to `main` runs `.github/workflows/pages.yml`, which builds and
publishes to GitHub Pages. Pull requests build and check but do not deploy.
One-time repository setting: Settings → Pages → Source: **GitHub Actions**.
